# surya-demo-2

This repository contains Python code.

## Getting started

### Prerequisites

- Install Python 3. Check that it is available from your terminal:

  ```bash
  python3 --version
  ```

### Set up the project

From the repository directory, create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

On Windows, activate the environment with:

```powershell
.venv\Scripts\Activate.ps1
```

If the project has a `requirements.txt` file, install its dependencies:

```bash
python -m pip install -r requirements.txt
```

### Run the Python code

Run the project's entry-point script from the repository directory:

```bash
python main.py
```

Replace `main.py` with the name of the Python script you want to run. There is
no entry-point script or `requirements.txt` in the repository yet.
